# proprietary_vendor_samsung_k3gxx

Arquivos binários proprietários (.so, firmwares de modem, câmera e sensores) extraídos da ROM oficial da Samsung para o modelo SM-G900H.

## 🛠️ Tecnologias

- **Android Vendor System**
- **Proprietary Blobs**
- **Samsung Drivers**

## 📂 Estrutura do Projeto

- `proprietary/`: Binários organizados por diretório de destino do Android.
- `BoardConfigVendor.mk`: Configurações de inclusão no build.
