# Proprietary Vendor Blobs for Samsung Galaxy S5 Exynos 3G (k3gxx)

Proprietary binaries, prebuilt libraries, firmware images, and vendor makefiles for the **Samsung Galaxy S5 Exynos 3G (SM-G900H / `k3gxx`)** targeting **LineageOS 18.1 (Android 11)**.

## Overview

This repository supplies closed-source vendor components required for full hardware enablement on LineageOS 18.1:
- RIL (Radio Interface Layer) libraries (`libsec-ril.so`)
- Camera, audio, sensor, and power management firmware blobs
- GPU (Mali-T628) proprietary driver binaries
- Wi-Fi, Bluetooth, and NFC firmware firmware images (`bcm4354`, etc.)

## Usage

Integrated automatically under `vendor/samsung/k3gxx` during manifest synchronization and device build setup.
